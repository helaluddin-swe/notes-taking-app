# Notes Taking App

A modern note-taking application built with JavaScript, HTML, and CSS. Create, organize, search, and manage notes with a clean and intuitive user interface.

## Features
- Create notes
- Organize notes
- Search functionality
- User-friendly interface

## Installation
1. Clone the repository
2. Open `index.html` in your browser

## Usage
- Add new notes using the input field
- Edit or delete notes as needed.
